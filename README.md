## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/leojsmada-lang/DigitalBusinessCard.git
cd DigitalBusinessCard

# Install dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Build for Production

```bash
npm run build
```

Outputs a production-ready bundle to the `/build` folder.
